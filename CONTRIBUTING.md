# Contributing

Thank you for your interest in contributing to this project!

## Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/vscodeweb.git
   cd vscodeweb
   ```
3. **Create a feature branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Making Changes

### Dockerfile Changes
- Test locally or on Railway before submitting
- Keep the image size reasonable
- Document any new tools or extensions added
- Update the README if you add significant functionality

### Documentation
- Keep the README up-to-date with any new features
- Use clear, concise language
- Include examples where helpful

## Submitting Changes

1. **Commit with clear messages:**
   ```bash
   git commit -m "Add feature: description of what changed"
   ```
2. **Push to your fork:**
   ```bash
   git push origin feature/your-feature-name
   ```
3. **Open a Pull Request** on the main repository with:
   - Clear title and description
   - Explanation of what problem it solves
   - Any testing you've done

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help others succeed

## Questions?

Open an issue to discuss ideas or ask questions before diving into large changes.
